# Artwork (optional, not included)

The page looks for these files here. Without them it uses plain colors and text.

| File | What to use |
| --- | --- |
| `logo.png` | A logo with a transparent background |
| `hero.jpg` | Landscape wallpaper for the start screen |
| `clips.jpg` | Landscape wallpaper shown behind your clips |

Run `python3 get-art.py` in the project folder to get the official ones, or pick others yourself: https://www.rockstargames.com/VI/media/artwork-wallpapers

They belong to Rockstar Games and are for personal, non-commercial use under its [legal terms](https://www.rockstargames.com/legal). Git ignores this folder so they stay on your computer. Don't commit them or host them publicly.
